 Project 2: Exploratory Data Analysis (EDA)

Objective

The objective of this project was to analyze a cleaned e-commerce dataset and identify trends, patterns, and key statistics using Python and data visualization techniques.

Tools Used

* Python
* Pandas
* Matplotlib
* Seaborn

Dataset Summary

* Total Records: 1200
* Total Columns: 14
* No missing values were found in the dataset.

Key Findings

1. The dataset contains 1200 customer orders collected between January 2023 and June 2025.
2. The average order value is approximately 1053.97.
3. The median order value is 823.62, indicating some high-value orders influence the average.
4. Printer was the most frequently purchased product category.
5. Instagram was one of the leading referral sources bringing customers to the platform.
6. Most customers purchased between 4 and 7 items per order.
7. The maximum order value recorded was 3456.40.

Conclusion

The exploratory analysis provided valuable insights into customer purchasing behavior, product popularity, and sales performance. The generated visualizations helped identify distributions and relationships within the dataset, making it easier to support future business decisions.
